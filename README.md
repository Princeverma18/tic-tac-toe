# Tic Tac Toe

## Overview

Tic Tac Toe is a classic two-player game built as a web application. Players take turns marking a square in a 3x3 grid with either an 'X' or an 'O'. The game is built using HTML, CSS, and JavaScript, providing a simple yet engaging user interface.

## Features

- **Two-player Mode:** Play against a friend in a local two-player setup.
- **Reset Game:** Restart the game to play again without refreshing the page.
- **Score Tracking:** Keep track of wins for both players.
- **Responsive Design:** The application is designed to work seamlessly on desktop and mobile devices.

## Technologies Used

- **HTML:** Structure of the web application.
- **CSS:** Styling and layout of the application.
- **JavaScript:** Game logic and interactivity.
